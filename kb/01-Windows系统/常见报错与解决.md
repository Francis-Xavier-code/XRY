# Windows 11 常见报错与解决

## 系统卡顿 / 内存吃紧

- 任务管理器 → 性能：看内存占用与磁盘占用
- 进程占用高：任务管理器 → 进程 → 按内存/CPU 排序，结束异常进程
- 长期卡顿：清理启动项、磁盘清理、`sfc /scannow`，检查是否杀毒软件全盘扫描中

## 磁盘空间不足

- 设置 → 系统 → 存储 → 临时文件（清理 Windows 更新缓存、回收站）
- `cleanmgr` 选择系统盘执行；卸载不用的软件
- 检查 `C:\Users\<用户名>\AppData\Local\Temp` 里的大文件（hilia 的临时文件在这里）
- 不要手动删除 Windows 目录（C:\Windows）下的文件

## 网络连不上

- 检查 Wi-Fi 开关与飞行模式
- 设置 → 网络和 Internet → 高级网络设置 → 网络重置
- 命令行：`ipconfig /release` 后 `ipconfig /renew`；`netsh winsock reset` 后重启
- 校园网：确认是否需登录认证页面（浏览器自动跳转）

## 软件打不开 / 闪退

- 右键 → 以管理员身份运行
- 设置 → 应用 → 已安装的应用 → 修复/重置
- 缺少运行库：安装 VC++ 运行库（微软官网下载 vcredist）

## 蓝屏 / 死机

- 记录错误码（如 PAGE_FAULT_IN_NONPAGED_AREA）
- 重启后查看 设置 → 系统 → 恢复 → 高级启动 → 诊断
- 常见原因：驱动冲突（更新显卡驱动）、内存故障（Windows 内存诊断）、磁盘故障

## 打印机 / 外设不识别

- 设置 → 蓝牙和其他设备 → 添加设备
- 打印机：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加打印机
