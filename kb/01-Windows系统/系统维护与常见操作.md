# Windows 11 系统维护与常见操作

## 基础信息查询

- 系统版本：`winver`（或 设置 → 系统 → 关于）
- 硬件信息：`systeminfo`；显卡：`dxdiag`
- 内存/CPU 实时占用：Ctrl + Shift + Esc 任务管理器

## 常用设置入口

设置（Win + I）：

- 系统 → 显示/声音/通知/电源/存储/屏幕
- 个性化 → 背景/主题/锁屏/任务栏/开始
- 应用 → 已安装的应用/启动/默认应用
- 账户 → 登录选项（PIN/指纹/人脸）
- 时间和语言 → 语言（输入法、语音识别、OCR 语言包）
- 网络和 Internet → Wi-Fi/以太网/代理/VPN
- 更新 → Windows 更新

## 开机自启管理

- 任务管理器 → 启动应用：查看/禁用自启项
- 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`：自启命令
- 计划任务：`taskschd.msc`（如 hilia 的桥接自启计划任务）

## 常见维护操作

- 磁盘清理：`cleanmgr`（或 设置 → 系统 → 存储 → 临时文件）
- 系统文件检查：管理员 PowerShell 运行 `sfc /scannow`；`DISM /Online /Cleanup-Image /RestoreHealth`
- 重置网络：设置 → 网络和 Internet → 高级网络设置 → 网络重置
- 重启资源管理器：任务管理器 → Windows 资源管理器 → 重新启动
- 查看端口占用：`netstat -ano | findstr :端口`，`tasklist | findstr PID`，`taskkill /PID 进程号 /F`

## Windows 更新

- 设置 → 更新 → Windows 更新 → 检查更新
- 更新前建议备份重要数据（见 08-数据与备份）
- 更新失败常见原因：磁盘空间不足、第三方杀软干扰；先清理空间再重试
