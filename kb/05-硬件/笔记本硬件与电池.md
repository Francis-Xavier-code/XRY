# 笔记本硬件与电池（Windows）

## 查看硬件信息

- `systeminfo`：系统、主板、内存总览
- `dxdiag`：显卡、驱动、DirectX
- `Get-CimInstance Win32_Processor` / `Win32_PhysicalMemory` / `Win32_DiskDrive`

## 电池健康

- `powercfg /batteryreport`：生成 HTML 电池报告（设计容量/充满容量/循环次数）
- 查看当前电量：`Get-CimInstance Win32_Battery`
- 充电阈值（延长电池寿命）：Windows 无通用设置，用厂商工具：
  - 联想：联想智能引擎 / Lenovo Vantage（电池养护模式）
  - 华硕：MyASUS（电池健康充电）
  - 戴尔：Dell Power Manager
  - 惠普：HP 支持助手 / BIOS 设置

## 性能相关

- 电源模式：设置 → 系统 → 电源 → 电源模式（最佳性能/平衡）
- 独显/核显切换：NVIDIA 控制面板 / 厂商显卡软件中设置
- 散热积灰、风扇异响 → 送修/清灰
- 硬盘：SSD 剩余空间建议保留 10% 以上，否则掉速明显

## 外设

- 蓝牙：设置 → 蓝牙和其他设备
- 显示器：Win + P 切换投影模式；多显示器在 设置 → 系统 → 屏幕 排列
- 快捷键：Fn + 亮度/音量组合键，不同品牌位置不同（参考键盘上 Fn 图标）
