# 网络问题排查（Windows）

## 快速排查顺序

1. 看右下角网络图标是否正常（有感叹号 = 没网或受限）
2. 浏览器能否打开网页；打不开 → 检查是否需登录校园网认证页
3. 其他设备是否有网 → 判断是电脑问题还是网络问题
4. 重启路由器 / 电脑（解决 80% 问题）

## 常用命令

```powershell
ipconfig /all                 # 本机 IP、网关、DNS
ipconfig /release; ipconfig /renew   # 重新获取 IP
Test-Connection baidu.com     # ping 外网
netsh winsock reset           # 重置 Winsock（需重启）
```

## 代理设置

- 命令行工具默认不走系统代理；需要时：
  `$env:https_proxy = "http://127.0.0.1:7890"`（端口按实际代理软件）
- 系统代理：设置 → 网络和 Internet → 代理

## 校园网常见问题

- 认证页打不开：换浏览器 / 清 DNS 缓存（`ipconfig /flushdns`）
- 宿舍断网：检查网线/网口；报修联系校园网中心
- 多设备限制：部分校园网限制设备数，先在认证页注销旧设备

## DNS 问题

- 网页能开、部分网站打不开 → 换 DNS：设置 → 网络 → DNS → 手动填 223.5.5.5 / 119.29.29.29
- `ipconfig /flushdns` 清 DNS 缓存
