# Windows 11 效率技巧与快捷键

## 高频快捷键

| 快捷键 | 功能 |
|---|---|
| Win + I | 设置 |
| Win + E | 文件资源管理器 |
| Win + D | 显示桌面 |
| Win + L | 锁屏 |
| Win + V | 剪贴板历史 |
| Win + Shift + S | 截图工具（截取后自动进剪贴板） |
| Win + G | Xbox Game Bar（录屏/性能面板） |
| Win + Tab | 任务视图/虚拟桌面 |
| Ctrl + Shift + Esc | 任务管理器 |
| Alt + Tab | 切换窗口 |
| Win + ← / → | 分屏 |
| Win + . | 表情符号面板 |
| Ctrl + Shift + T | 浏览器恢复关闭的标签页 |

## 希尔娅专属快捷键

- Alt + G：迷你对话窗口
- Alt + H：打开面板

## 多任务技巧

- 虚拟桌面：Win + Ctrl + ←/→ 切换，Win + Ctrl + D 新建
- 贴靠布局：把鼠标悬停在窗口右上角「最大化」按钮上
- 三指/四指触控板手势：设置 → 蓝牙和其他设备 → 触控板

## 文件资源管理器技巧

- 快速访问：把常用文件夹固定到「快速访问」
- 显示扩展名：查看 → 显示 → 文件扩展名
- 剪贴板历史 Win + V 可固定常用文本（如学号、地址）

## 终端技巧

- PowerShell 用 Tab 补全；`Ctrl + R` 搜索历史命令
- 打开当前文件夹的终端：地址栏输入 powershell 回车
