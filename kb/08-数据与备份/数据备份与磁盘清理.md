# 数据备份与磁盘清理（Windows）

## 备份思路

- 重要文件（论文、课程资料、学分数据）至少两份：本地 + 云盘/移动硬盘
- 希尔娅的数据在 `%LOCALAPPDATA%\hilia`（对话、记忆、学分数据库都在这里），
  备份时整个目录拷走即可
- 系统级备份：设置 → 系统 → 存储 → 高级存储设置 → 备份选项（文件历史）

## 希尔娅自带备份

- `hilia backup now`：把对话/记忆/配置打包成本地 Git 快照（自动去重）
- 面板：托盘菜单 → 立即备份
- 定时：任务计划程序建一个 ONLOGON/每日任务跑 `hilia backup now` 即可

## 磁盘清理

```powershell
cleanmgr            # 磁盘清理（选系统盘）
Get-ChildItem $env:TEMP | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue  # 清临时文件
```

- 设置 → 系统 → 存储 → 临时文件：Windows 更新缓存、回收站、下载
- 卸载不用的软件（winget list 查看已装软件）
- 大文件排查：`Get-ChildItem C:\ -Recurse -File -ErrorAction SilentlyContinue | Sort Length -Descending | Select -First 20`

## 不要做的事

- 不手动删 `C:\Windows` 下的文件
- 不关闭虚拟内存（除非明确知道后果）
- 不做「磁盘碎片整理」在 SSD 上（系统会自动处理）
