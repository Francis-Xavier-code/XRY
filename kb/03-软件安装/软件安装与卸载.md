# 软件安装与卸载（Windows）

## winget（微软官方包管理器，Win10 1809+ 自带）

```powershell
winget search 微信          # 搜索
winget install WeChat       # 安装（按 ID/名称）
winget upgrade --all        # 升级已装软件
winget uninstall WeChat     # 卸载
```

- 安装前可用 `winget show <包名>` 查看来源与版本
- 优先选择 `Microsoft Store` / 官方源标记的包

## 软件来源安全判断

1. 微软商店（最稳妥）
2. 软件官网下载（注意域名，如 weixin.qq.com、wps.cn）
3. winget / 知名分发渠道
4. 不明网站的「一键安装包」「破解版」一律拒绝

- 安装时警惕捆绑：取消勾选「安装全家桶/浏览器主页/开机自启」
- 下载的安装包先杀毒扫描再运行

## 常用软件

- 办公：WPS / Office（学校一般有正版授权）
- 聊天：微信、QQ、飞书
- 浏览器：Edge（自带）、Chrome
- 压缩：7-Zip（`winget install 7zip.7zip`）
- 截图：微信/QQ 自带、Snipaste（`winget install Snipaste`）
- 卸载残留：设置 → 应用 → 已安装的应用 → 卸载；残留配置在 `%APPDATA%` 和 `%LOCALAPPDATA%` 对应目录

## 开机自启

- 任务管理器 → 启动应用
- 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- 计划任务 `taskschd.msc`（希尔娅桥接的自启方式）
