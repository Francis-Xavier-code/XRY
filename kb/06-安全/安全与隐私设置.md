# Windows 安全与隐私设置

## 基础安全习惯

- 开启 Windows 更新（设置 → 更新 → Windows 更新）
- 账户使用 Microsoft 账户 + PIN/指纹/人脸（设置 → 账户 → 登录选项）
- 杀毒：Windows Defender 已内置且够用，不必装第三方全家桶
- 不明邮件附件、U 盘、下载的 exe 一律先杀毒

## 隐私设置（设置 → 隐私和安全性）

- 关闭不用的位置/相机/麦克风后台权限
- 广告 ID：设置 → 隐私和安全性 → 常规 → 关闭广告 ID
- 诊断数据可设为「必需」

## 家庭共享 / 多用户

- 设置 → 账户 → 其他用户：添加家人/同事账户
- 学生共用电脑可给标准用户（非管理员）账户

## 网络安全

- 公共 Wi-Fi 避免登录网银；敏感操作走手机热点
- 设置 → 网络和 Internet → Wi-Fi → 随机硬件地址（公共网络建议开启）
- 不明链接不点；QQ/微信里的「客服」「退款」链接多为诈骗

## 数据加密

- BitLocker：设置 → 系统 → 存储 → 高级存储设置 → 磁盘和卷 → 启用 BitLocker（笔记本建议开启）
- 开启前务必备份恢复密钥（微软账户里可存）
