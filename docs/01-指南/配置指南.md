# 配置指南：模型通信与工具

GQY 的所有配置集中在一个文件：`GQY_HOME/config/config.jsonc`（JSONC 格式，支持注释）。配置方式有三种：`gqy config` 的 TUI、直接编辑文件、对话里让 GQY 帮你改。

## 一、模型通信（谁在回答她）

### 顶层结构

```jsonc
{
  "active_provider": "opencode",        // 当前生效的供应商 id
  "providers": [ /* 供应商列表 */ ],
  "active_multimodal_provider_models": [ /* 识图用的模型 */ ],
  "tools": { "enabled": true, "loading_mode": "lazy" },
  "plugins": { /* 工具插件开关 */ },
  "mcp": { "enabled": false, "servers": [] },
  "skills": { "enabled": true },
  "display": { "language": "auto" },
  "prompt": { "active_persona": "" },
  "memory": { "enabled": true }
}
```

### 供应商（Provider）字段

`providers` 是数组，每个供应商：

```jsonc
{
  "id": "my-openai",                    // 唯一 id
  "display_name": "我的 OpenAI",
  "base_url": "https://api.openai.com/v1",   // OpenAI 兼容接口地址
  "protocol": "openai",                 // openai | anthropic
  "api_key": "$env:MY_API_KEY",         // 见下方「密钥三种写法」
  "models": ["gpt-4o-mini"],            // 可用模型列表
  "default_model": "gpt-4o-mini",       // 默认对话模型
  "model_context_window": { "gpt-4o-mini": 128000 },  // 各模型上下文窗口
  "timeout_seconds": 60,
  "temperature": 0.7,
  "anthropic_max_tokens": 8192
}
```

### 密钥三种写法

1. **直接填**：`"api_key": "sk-xxxx"`（明文，会被备份脱敏——快照里自动清空，恢复后需重填）
2. **环境变量引用**：`"api_key": "$env:MY_API_KEY"`（推荐，密钥不进配置文件，备份零风险）
3. **多密钥轮换**：逗号分隔 `"sk-a,sk-b"` 或多个 `$env:`，GQY 会自动轮换/重试

### 默认服务

开箱即用 [opencode](https://github.com/anomalyco/opencode) 公共服务（`big-pickle` 等），无需任何 key。想换自己的模型：`gqy config` → 「配置文本模型」→ 添加供应商 → 填 base_url 和 key。

### 通信排障

| 现象 | 处理 |
|---|---|
| 401 / 认证失败 | 检查 api_key 写法、`$env:` 变量是否已 export |
| 连接超时 | 确认 base_url 可达（`curl -I <base_url>`）；换 `timeout_seconds` |
| 404 / 模型不存在 | `models` 和 `default_model` 拼写；确认服务商模型名 |
| 响应乱码/中断 | 检查 `protocol`（anthropic 系服务要选 anthropic）；部分模型兼容性差，换模型 |
| 工具调用不生效 | 模型需支持 function calling；`gqy config` 里换支持工具的模型 |

## 二、工具（她能干什么）

### 插件开关（plugins 段）

`gqy config` → 「插件配置」可视化开关，对应 config.jsonc：

```jsonc
"plugins": {
  "web":         { "enabled": true, "max_results": 8, "tavily_api_keys": [] },
  "web_images":  { "enabled": true },
  "deep_research": { "enabled": true },
  "vision":      { "enabled": true },
  "image_generation": { "enabled": false },   // 生图默认关，需配 API
  "memes":       { "enabled": true },
  "knowledge_base": { "enabled": true },
  "man":         { "enabled": true },
  "moegirl":     { "enabled": true },
  "weather":     { "enabled": true },
  "exchange_rate": { "enabled": true },
  "xuanxue":     { "enabled": true },
  "calculator":  { "enabled": true },
  "hash_codec":  { "enabled": true },
  "diagnostics": { "enabled": true },
  "memory":      { "enabled": true }
}
```

### 自定义工具三渠道

1. **脚本工具**：把可执行脚本（任意语言）放进 `GQY_HOME/config/scripts/`，GQY 会注册为可调用工具。脚本头部写 `Description: xxx` 可自定义工具描述。对话里说「注册脚本 /path/to/xxx」也行。
2. **skills**：`GQY_HOME/config/skills/` 下的 SKILL.md 定义技能，用 `load_skill` 加载，适合封装固定工作流。
3. **MCP**：config.jsonc 的 `mcp.servers` 配置 MCP 服务器（stdio 或 HTTP），GQY 就能用 MCP 生态的工具（文件系统、数据库、浏览器等）：

```jsonc
"mcp": {
  "enabled": true,
  "servers": [
    {
      "name": "filesystem",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/mac"]
    }
  ]
}
```

### 工具权限与安全

- 工具调用需模型发起，关键操作（写文件、执行命令）会经权限控制；
- 不确定的工具先关掉对应插件再试；
- 自定义脚本只在 `GQY_HOME/config/scripts` 下注册，来源要可信。

## 三、知识库

- 导入：`gqy kb add kb/`（目录递归），检索：`gqy kb search <词>`，列表：`gqy kb list`
- 存储：`GQY_HOME/data/kb/`，随备份快照
- 仓库自带 macOS 知识库在 `kb/`，按主题分子目录；brew 安装时随包放在 `$(brew --prefix)/share/gqy/kb`，一条命令导入：
  ```
  gqy kb add "$(brew --prefix)/share/gqy/kb"
  ```

## 四、其他常用配置

| 配置 | 位置 | 说明 |
|---|---|---|
| 界面语言 | `display.language` | auto/en/zh，或环境变量 `GQY_LANG` |
| 只读资源目录 | 环境变量 `GQY_SHARE_DIR` | 覆盖内置脚本/表情/知识库源的查找位置（默认自动从可执行文件位置推断） |
| 人格覆盖 | `prompt.active_persona` | 多人格时切换 |
| 自定义系统提示词 | `system_prompt_file` | 指向 md 文件时覆盖内置人格 |
| 上下文压缩阈值 | `context.trim_at_ratio` | 默认 0.9，上下文用到 90% 触发压缩 |
| 记忆开关 | `memory.enabled` 等 | 自动日记/联想/遗忘 |
