# 中继服务器部署指南（APK ↔ Windows 互联网通信）

Windows 电脑通常在 NAT 后没有公网 IP，Android 手机无法直连。消息经中继服务器转发。

## 一、架构

```
手机 App ──wss──┐                    ┌──wss── Windows（hilia relay bridge）
                ├── relay-server ────┤
扫码配对/对话    └────────────────────┘
                配对码一次性 / token 认证 / 消息路由 / 离线队列
```

## 二、部署（VPS）

```bash
# 1. 拉取代码（或直接复制 relay-server 目录）
git clone https://github.com/Francis-Xavier-code/XRY
cd XRY/relay-server

# 2. 安装依赖
npm ci

# 3. 启动（默认 8787 端口）
npm start
```

生产环境建议用 systemd 托管：

```ini
# /etc/systemd/system/hilia-relay.service
[Unit]
Description=Hilia Relay Server
After=network.target

[Service]
WorkingDirectory=/opt/XRY/relay-server
ExecStart=/usr/bin/node index.js
Restart=always
Environment=PORT=8787

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now hilia-relay
```

## 三、TLS（必须）

扫码内容里的 `wss://` 需要有效证书，否则手机连不上。任选其一：

**Caddy（推荐，自动证书）**：

```caddyfile
relay.example.com {
    reverse_proxy 127.0.0.1:8787
}
```

**Nginx**：

```nginx
server {
    listen 443 ssl;
    server_name relay.example.com;
    # ssl_certificate /etc/letsencrypt/live/relay.example.com/fullchain.pem;
    # ssl_certificate_key /etc/letsencrypt/live/relay.example.com/privkey.pem;
    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 300s;
    }
}
```

## 四、Windows 端配置

```powershell
hilia relay config relay_url wss://relay.example.com/ws
hilia relay install      # 向中继注册桌面设备 + 开机自启
hilia relay status       # 查看状态与日志
```

配置完成后，面板 → 设置 → 设备配对 → 生成配对二维码，手机扫码即可。

## 五、Cloudflare Workers 适配（可选）

本实现基于 Node `ws` 库。Workers 使用原生 WebSocket 且状态需放入
Durable Objects（否则多实例不同步）。迁移时复用 `index.js` 的
配对/消息路由/限流逻辑，仅替换传输层（`handleWs` → `worker.onmessage`）。
建议有 VPS 时优先自建。

## 七、安全清单

- [x] 配对码一次性 + 5 分钟过期
- [x] session token 32 字节随机
- [x] 消息上限 64KB、限流 10 条/秒/设备
- [x] 离线消息仅内存暂存（重启即清空，不落盘）
- [ ] 生产启用 WSS/TLS（反向代理）
- [ ] 如需多实例/容灾：加 Redis 共享状态（当前单机部署即可）
