# 激活码、更新签名与防逆向（开发者）

本文面向**开发者本人**（维护者），说明激活码签发、更新清单签名、防逆向机制与密钥管理。
普通用户无需阅读。

## 一、密钥体系

整套信任体系基于一对 Ed25519 密钥：

| 用途 | 存放位置 | 说明 |
|---|---|---|
| 私钥 | 开发者本机 + GitHub Secrets（`HILIA_SIGN_KEY`） | 签发激活码、签名 update.json；**绝不进仓库** |
| 公钥 | `src/security.rs`（Windows，obfstr 混淆）与 `android/lib/app_config.dart`（APK，XOR 混淆） | 客户端仅验签，无法伪造 |

生成新密钥对（生产部署前必须替换开发密钥）：

```bash
hilia keys gen
```

输出私钥（保存到 GitHub Secrets）与公钥（base64 填入 `src/security.rs` 与
`android/lib/app_config.dart` 并重新构建两端）。`tools/update-signer` 的签名
规范与客户端 `src/update.rs` 完全一致（已用测试验证同输入同签名）。

## 二、签发激活码

```bash
# 格式：<plan>|<user>|<expires_at 秒或 0>
# 0 = 永久；如 2027-01-01 到期：$(date -j -f "%Y-%m-%d" 2027-01-01 +%s)（macOS）或 date -d 2027-01-01 +%s（Linux）
HILIA_SIGN_KEY=<私钥base64> hilia keys sign-license "pro|辅导员姓名|0"
```

输出形如 `HILIA1.<payload>.<signature>`，发给用户后：

- 用户执行 `hilia license activate <激活码>`（Windows）
- 或 APK 设置 → 激活 → 输入激活码

客户端验证：payload base64 解码 → Ed25519 验签（内置公钥）→ 有效期检查 → 写入配置。

## 三、签名 update.json

发布新版本时，CI 工作流自动完成（`v*` tag 触发）：

1. Windows 工作流构建 zip → 计算 sha256/size → 生成 `update.json`（含多加速源 URL）
   → `hilia keys sign-update update.json` 签名 → 上传为 Release 资产
2. Android 工作流构建 APK → 生成 `update-apk.json` → `tools/update-signer sign` 签名 → 上传

手动签名（本地验证用）：

```bash
HILIA_SIGN_KEY=<私钥> hilia keys sign-update update.json
# 或独立工具（无需构建 hilia）
tools/update-signer/target/release/update-signer sign update.json <私钥>
```

客户端验证逻辑：解析 → `signature` 置空 → 按结构体字段顺序序列化 → Ed25519 验签 →
sha256 校验下载包。任何一步失败即拒绝更新。

## 四、防逆向措施与边界

已实施：

- release 构建 `strip` + LTO + `panic=abort`（减小体积、去掉符号表）
- 关键字符串编译期混淆：内置公钥、端点等 `strings` 扫不到明文
- APK：Dart `--obfuscate` + R8（minify + shrink）+ 资源收缩
- 激活码/更新清单全部 Ed25519 签名验证，私钥只在开发者侧

边界（诚实说明）：**本地二进制无法做到绝对防破解**——攻击者可以 patch
验证逻辑。因此关键价值全部建立在签名与服务器侧：

- 伪造激活码：需要私钥 → 不可能
- 篡改更新源：需要私钥签名 → 不可能
- 破解本地验证：可能，但无法获得合法激活码/更新内容，且升级会被覆盖

如果未来做**在线订阅**（`license.server`），建议：激活状态由服务器签发短期
（如 24h）签名凭证，客户端每次启动校验，配合心跳续期，进一步缩小破解窗口。

## 五、GitHub Secrets 清单

| Secret | 用途 | 提供方 |
|---|---|---|
| `HILIA_SIGN_KEY` | 激活码/update.json 签名私钥（base64） | `hilia keys gen` |
| `HILIA_KEYSTORE_B64` | Android release keystore（base64） | `keytool -genkeypair ...` |
| `HILIA_KEYSTORE_PASS` | keystore 密码 | 同上 |
| `HILIA_KEY_ALIAS` | key 别名 | 同上 |
| `HILIA_KEY_PASS` | key 密码 | 同上 |
