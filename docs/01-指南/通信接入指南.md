# 通信接入指南（QQ / 企业微信 / 飞书）

希尔娅通过三套 Node.js 桥接接收消息，把平台消息转给本地 `hilia ask` 处理。
所有桥接都由 `hilia <platform> install` 注册为 Windows 计划任务（ONLOGON 开机自启）。

前置条件：本机安装 Node.js ≥ 22（`node --version` 确认）。

## 一、QQ（NapCat）

1. 安装 NapCat：
   - Windows 推荐 NapCat.QQ 一键版（官方发行包），运行后监听 `ws://127.0.0.1:3001`
   - 确保 WebSocket 服务已开启（NapCat 设置里打开 WS 服务）
2. 配置并安装桥接：

```powershell
hilia napcat config self_id <机器人QQ号>
hilia napcat install
hilia napcat status     # 查看状态与最近日志
```

3. 使用：
   - 学生私聊机器人直接发消息
   - 班级群聊里 `@机器人` 提问

## 二、企业微信

1. 企业微信管理后台（work.weixin.qq.com）→ 应用管理 → 创建自建应用：
   - 开启「接收消息」，生成 Token 与 EncodingAESKey（记下来）
   - 拿到企业 ID（corp_id）、AgentId、Secret
2. 配置并安装桥接：

```powershell
hilia wecom config corp_id <企业ID>
hilia wecom config agent_id <AgentId>
hilia wecom config secret <Secret>
hilia wecom config token <Token>
hilia wecom config encoding_aes_key <EncodingAESKey>
hilia wecom install
```

3. **回调 URL 需要公网可访问**（企业微信回调不支持本地地址）：
   - 方案 A：frp / cloudflared / 花生壳 把 `https://你的域名/wecom` 穿透到 `127.0.0.1:4097`
   - 方案 B：租一台小服务器跑反向代理（Nginx 转发到本机穿透通道）
   - 然后在后台「接收消息 → 设置 API 接收」填：URL = `https://你的域名/wecom`，
     Token / EncodingAESKey 与上面配置一致；提交后如提示验证成功即完成
4. 使用：
   - 把应用拉进班级群，群里 `@应用` 提问
   - 学生也可在企业微信里直接给应用发消息

## 三、飞书（无需公网地址）

1. 飞书开放平台（open.feishu.cn）→ 开发者后台 → 创建**企业自建应用**：
   - 开启「机器人」能力，发布版本
   - 事件订阅选「长连接模式」，订阅 `im.message.receive_v1`
   - 拿到 App ID 与 App Secret
2. 首次安装飞书 SDK 依赖（只需一次）：

```powershell
cd <希尔娅安装目录>\communication\feishu
npm ci
```

3. 配置并安装桥接：

```powershell
hilia feishu config app_id <App ID>
hilia feishu config app_secret <App Secret>
hilia feishu install
```

4. 使用：学生/辅导员在飞书里给机器人发消息，或拉进群后 `@机器人` 提问。

## 辅导员身份（admins）

`%LOCALAPPDATA%\hilia\config\bridges.json` 里登记辅导员的平台 ID：

```json
{
  "napcat": { "ws_url": "ws://127.0.0.1:3001", "self_id": "机器人QQ号" },
  "wecom": { "corp_id": "...", "agent_id": "...", "secret": "...", "token": "...", "encoding_aes_key": "..." },
  "feishu": { "app_id": "...", "app_secret": "..." },
  "admins": {
    "qq": ["辅导员QQ号"],
    "wecom": ["辅导员企业微信userid"],
    "feishu": ["辅导员飞书open_id"]
  }
}
```

- 登记在 admins 里的账号 = 管理员，可增删改学分
- 未登记的账号 = 学生，只能查自己的信息；首次使用先「绑定 学号 姓名」

## 日志与排障

- 日志位置：`%LOCALAPPDATA%\hilia\cache\logs\<platform>-bridge.log`
- `hilia <platform> status` 显示自启动状态与最后一条日志
- 改完桥接脚本后重启：`hilia <platform> uninstall` 再 `install`
- 手动跑桥接看输出：`node <安装目录>\communication\<platform>\bridge.cjs`

## 已知限制

- 企业微信回调需要公网地址（见上文方案 A/B）
- Windows 语音识别（STT）依赖系统语音包：设置 → 时间和语言 → 语言 → 中文 → 选项 → 语音识别
- 桥接目前为文本消息；图片/语音消息会转成占位符说明，不转发内容
